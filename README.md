# 明治法律辞書検索

明治期の法律辞書・法律辞典の見出し語・対訳語・語釈を横断検索する静的サイト。
サーバーは使わず、データを読み込んだブラウザ内で検索する（GitHub Pages でそのまま公開できる）。

## 収録辞書

- 加太邦憲=藤林忠良 編『佛和法律字彙』（知新社、1886）
- 磯部四郎 編『民法應用字解』（元老院、1887）
- 渡部万蔵 ほか『法律大辭典』（郁文舍、1908）

## 構成

```
index.html / app.js / style.css   画面と検索ロジック
data/entries.json                 見出し・読み・対訳・出典（最初に読み込む）
data/defs.json                    語釈本文（見出しの後に読み込む）
docs/<書誌ID>.html                辞書ごとの全項目一覧（トップの収録辞書の表からリンク）
```

`data/` の2ファイルと `docs/` の一覧ページは、このリポジトリの外にある変換プログラム
`法律辞書・法律辞典/program/build.py` が、元データ `法律辞書・法律辞典/data/*.json`（JSON-LD）から生成する。

## データの更新

`法律辞書・法律辞典/data/` の JSON-LD を差し替え・追加したら、`法律辞書・法律辞典/` 直下で:

```
python program/build.py
```

新しい辞書を追加した場合は、`program/build.py` の `DICTS` に略称・刊年・言語の向き・校正状況を書き足す。

## 検索の仕組み

- **見出し語・対訳語**：見出し・読み・対訳語の部分一致（空白区切りで AND）。完全一致・前方一致を上位に並べる。
  欧文の語は MiniSearch で一、二文字違いの綴り（contract → Contrat、OCR で残った Con-trat など）も拾い、部分一致の後ろに並べる。
- **語釈を含む全文**：語釈まで含めて全件を照合する。
- 照合の前に、旧字→新字（府県史料パイプライン make_data.py の KANJI_NORMALIZE を build.py が読み込む）、カタカナ→ひらがな、全角→半角、大文字→小文字、アクセント記号の除去をそろえて行う。
  この正規化は文字数を変えないので、一致位置をそのまま原文の強調表示に使っている。

## ローカルで確認

```
python -m http.server 8000
```

<http://localhost:8000/> を開く（`file://` では JSON を読み込めない）。
